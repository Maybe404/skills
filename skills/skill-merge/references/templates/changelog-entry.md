# CHANGELOG 条目模板

`merges/<id>/CHANGELOG.md` 面向用户，写这次合并让 skill 的行为变了什么，不写内部流程。新的一节加在标题下方，最新的在最上面。

规则 id 只在"规则变动"里出现，正文段落用人话写，不点 id。

---

## YYYY-MM-DD

一句话说明这次改了什么，用户能感觉到的变化。感觉不到变化的写"无行为变化"。

### 新增

- 现在会 <行为>。原因：<一句话>。

### 变更

- 原先 <旧行为>，现在 <新行为>。影响：<什么样的输入会得到不同结果>。

### 移除

- 不再 <行为>。原因：<一句话>。

### 规则变动

新增 <n> 条，修改 <n> 条，撤下 <n> 条。规则 id：<列出>。详见 reports/NNNN-YYYY-MM-DD-<slug>.md。

### 来源

这次涉及的来源：<source_id 列表>。来源清单的完整状态见 skills/<id>/SOURCES.md。
