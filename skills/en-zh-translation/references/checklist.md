# 交付前检查清单

逐项检查，全部通过再交付。带 * 的分组 `scripts/check_zh.py` 可以自动检查一部分。

## 意思

- [ ] 每一句都能回答"这句让读者知道什么或做什么"，并且和原文一致。
- [ ] 原文的每个论点、限定词、条件都在译文里有对应；没有为了缩短而删掉的。
- [ ] 译文里没有原文没有的比喻、成语、强调词、量词、语气词。
- [ ] 例子翻译后在中文里起同样的作用。

## 句子类型

- [ ] 定义句有"所谓……就是……"或"……指的是……"标记。
- [ ] 描述别人行为的句子带主语。
- [ ] 规则句有情态词（必须 / 应当 / 可以 / 不要 / 不得），强度和原文一致。
- [ ] 条件句的条件和动作各自成分句："X 时，做 Y"。
- [ ] 失败分支写出来了：X 失败了怎么办。

## 指代

- [ ] 人称表只有一套，全文一致。
- [ ] 它 / 其 / 这个 / 自己都能唯一指向一个名词。
- [ ] 动词的对象都写出来了：验证什么、注明什么、报告给谁。

## 数字和逻辑 *

- [ ] 数字、百分比、次数、阈值与原文逐个相同。
- [ ] 阈值方向正确：超过 / 最多 / 至少。
- [ ] 否定辖域、or 的可兼性、unless / until 的方向正确。
- [ ] 单复数、每个 / 所有、时态体貌没有丢。

## 术语和代码 *

- [ ] 术语处理方式全文一致；首次出现有括注。
- [ ] 代码、命令、路径、标识符、占位符原样，内部标点半角。
- [ ] 报错和日志原文照贴。

## 排版 *

- [ ] 中文正文全角标点，中英文与数字之间有空格。
- [ ] 一句最多一个冒号。
- [ ] 标题级别、列表层级、换行、代码块位置和原文一致。
- [ ] 标题范围和正文内容一致。

## 风格

- [ ] 译文遵守它自己规定的风格（规则文本是样本）。
- [ ] 没有"吧、呢、啊"，没有反问句，没有原文没有的"我们"。
- [ ] 半比喻词（命中、胜者、闸门、跑通、落地）换成字面词。

## 交付

- [ ] 附"不确定项"清单：原文歧义、指代不明处、所做假设。
- [ ] 没有替作者做原文没有做的决定。
