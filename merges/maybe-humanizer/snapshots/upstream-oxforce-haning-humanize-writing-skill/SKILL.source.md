# 中文行文自然化

把 AI 深度参与的中文文稿修到自然、可信并像作者本人。把检测脚本当作启发式检查器，不把它当作作者身份判定器或检测规避器。

## 基本原则

1. 先保护事实、引用、数据、专有名词、限定语和 AI 参与标注，再处理表达。
2. 判断看语境和特征簇，不凭一个词、一个破折号或一处正式表达下结论。
3. 作者声纹与语体要求优先于通用阈值。阈值只负责提示人工复核，不自动决定改写。
4. 优先恢复作者已经写过的真实细节；没有可靠来源就标记【补真实细节】，不得编造。
5. 目标是读者体验与作者辨识度，不以第三方检测分数作为验收门。

现有研究主要讨论英语检测器，且结果随模型、阈值、文本长度与人群变化；它们不能证明中文文稿存在统一、稳定的“AI 指纹”。研究范围见 `NOTICE.md`。

## 运行模式

| 模式 | 做什么 | 适用 |
|---|---|---|
| **检测** | 跑脚本并完成人工两查，引用原文列问题，不改稿 | 用户想自己改，或先诊断 |
| **清洗**（默认） | 检测 → 改写 → 复检，另存新版本 | 常规修订 |
| **收敛** | 清洗后复检，必要时再修一轮；最多 2 轮 | 重要发布稿 |

## 强度

- **轻度**：清聊天残留和明显套式表达，不动结构。
- **中度**（默认）：再处理节奏、段落和章节模板感，但保留专业密度与术语纪律。
- **深度**：按作者样文重塑语气。必须先取得 1–2 篇本人样文；样本不足时只给低置信度建议，不模仿。

## 交互

只在用户明确触发本 skill 或项目配置已约定例行检查时执行。不要把普通“润色”自动扩大成反 AI 清洗。

需要询问时，把模式、强度、语体合并成一次询问。能从请求、文稿或 `config.md` 推断的不问。无人值守时使用“清洗 / 中度 / 按文稿推断语体”，并在报告首行声明参数。

## 语体档案

| 语体 | 优先保护 | 重点检查 |
|---|---|---|
| **学术/长文** | 限定语、术语、引用、方法学被动 | 空洞过渡、同构章节、无来源断言 |
| **公众号/博客** | 第一人称、情绪、短段、设问 | 套式金句、机械排比、播报感 |
| **公文/公司文稿** | “一是…二是”、规范程式语 | 聊天残留、无信息重复、虚假具体化 |
| **邮件/短文** | 问候、签名、直接语气 | 对话助手残留、过度扩写 |

公文程式不等于 AI 腔；学术严谨不等于机器腔；专业术语重复通常是术语纪律，不要为了“更人”而轮换。

## 声纹校准

深度档先运行 `python scripts/voiceprint.py 样文.md [样文2.md ...]`，再人工核对句长、用词档位、段落开头、标点和惯用转折。低置信度画像只作提问线索，不直接驱动模仿。

把确认后的画像写入 `config.md`。改写时用作者已出现的模式替换套式模式，不把全文改成“干净的通用文风”。

## 三遍流程

### 1. 检测

1. 运行 `python scripts/check.py <文稿> --genre <general|academic|blog|official|email>`。对比两版用 `--compare 旧稿 新稿`；白名单用 `--whitelist "完整词,另一词"`。
2. 人工检查脚本无法判断的两项：每节是否机械收尾；章节是否重复同一模板。
3. 按严重度列问题，引用脚本给出的行号和原文片段。单点命中先判断语境，特征簇才优先处理。

### 2. 改写

按需读取 `references/指纹清单.md` 和 `references/改写手法.md`：

1. 只改表达，不改事实。拿不准就保留并提问。
2. 清除明确的聊天残留；其他套式短语逐处判断，不做机械替换。
3. 把破折号、加粗、排比、段长和句长阈值当作默认审阅基线；语体或已确认声纹可以覆盖。
4. 打破无意义的均匀，不刻意制造“一句话段”或“十行长段”。优先保证手机阅读、逻辑和语义完整。
5. 允许章节不对称，但不要为了不对称撤掉必要的表格、总结或论证。
6. 优先还原早期草稿中的第一人称经验。只在个人表达型文稿中建议补第一人称，其他语体不得强加。

### 3. 复检

1. 运行 `python scripts/check.py --compare 原稿 新稿 --genre <语体>`。
2. 核对事实、数字、年份、引用、链接、专有名词与 AI 标注是否逐项保持。
3. 朗读三个代表段落，处理播报感，同时保护作者本来的停顿和句法习惯。
4. 列出保留项与理由，不把所有提示都“清零”。

## 停机判据

满足以下条件即停：

- 聊天残留与编造内容为零；
- 事实、引用、数据、限定语和标注保持不变；
- 中风险项已处理，或逐项写明语体/声纹保留理由；
- 读者体验自然，作者辨识度没有下降。

最多两轮。检测器分数、提示级计数和固定节奏预算都不是继续改写的充分理由。

## 输出

清洗模式交付四样：另存的新版本、前后计数、分类改动摘要、残留与保留理由。检测模式只交付带行号和原文片段的问题清单。不得覆盖原稿。

## 本机配置

文件夹安装时，可按 `config.example.md` 创建 `config.md`，保存默认模式、语体、白名单、样文路径和经确认的声纹画像。通过只读 `.skill` 安装时，把偏好写进项目指令或在对话中声明。

## 边界

- 不承诺通过任何检测器，不把检测分数写进达标线。
- 不为降低可预测性而替换准确术语、制造错别字或破坏语法。
- 不伪造经历、对话、数据和引用。
- 不删除必要的 AI 参与标注。
- 不在样本不足时强行模仿作者。
- 不把私密样文、`config.md` 或文稿内容上传到外部服务，除非用户明确授权。
