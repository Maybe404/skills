# 中文模式表（精简）

先按**问题族**处理，词条只作代表。新口癖尽量归入现有族，不急着加词。
单独出现且信息完整的常见词（如「此外」「重要」）**不要**见词就砍；扎堆或纯姿态时再动。

## 通常直接处理

| 问题族 | 代表触发 | 默认动作 |
|--------|----------|----------|
| 开场套话 | 值得注意的是、让我来解释、结论先说、直接说结论 | 删引导，留后续实质 |
| 谄媚/颁奖 | 你说得很对、一针见血、好问题、顶刊级 | 删；回到具体判断 |
| 空总结收尾 | 综上所述、归根结底、本质上、总的来说 | 删；停在最后具体点 |
| 发布宣言 | 系统性升级、全新跃迁、能力矩阵、共同见证 | 改成变更/限制清单 |
| 无源权威 | 研究表明、数据显示、专家认为、业内普遍认为 | 有独立证据才 rewrite-safe；否则 audit-only / placeholder / 按 scope 删除 |
| 二元/否定拔高 | 不是 X 而是 Y、不仅仅…更是…、与其…不如… | 多数直接说 Y 或具体命题 |
| 商业/工程黑话 | 赋能、抓手、兜住、打通、对齐颗粒度（「闭环」仅指管理套话，控制闭环保留） | 换成具体动作或删除 |
| 行业简称/截短词 | 现网、待拍、拍下一组、落盘、上量 | 除面向专业读者的固定术语外，按语境换成最短常见说法；短说法有歧义时只补必要信息 |
| 含糊或截短动作 | 过一下、走一遍、往下拍、往下走 | 看实际对象，不按「回滚」等修饰词判断；方案、步骤、清单等内容可按通常含义改写，可能改变系统或数据时先确认具体动作 |
| 假洞见 | 真正重要的是、大多数人忽略、底层逻辑是 | 删架子；有判断就直说判断 |
| 推销尾 | 要不要我顺便、你一句话的事、已经测过绝对没问题 | 删或改成可核实的下一步 |
| 协作腔残留 | 希望对你有帮助、如有需要请随时 | 删 |

## 扎堆才处理

| 问题族 | 代表触发 | 默认动作 |
|--------|----------|----------|
| 连接词堆叠 | 此外、同时、另外、不仅、并且 同段多次 | 保留必要逻辑连接，其余删 |
| 渲染修饰 | 全面、深度、显著、有效、持续 连用 | 有数据就留数据；无数据则降调或删 |
| 旁白解释 | 这说明、这意味着、彰显了 | 改成直接事实句 |
| 同义词轮换 | 同一对象在相邻句换三个称呼 | 固定一个名称 |

## 仅全文过密

重要、关键、核心、提升、优化、赋能（轻度）、显著 — 只替换重复中的一部分，避免全文漂白。

## 结构反模式（无固定词）

| 结构 | 处理 |
|------|------|
| 宏大时代开场 | 删，从对象与问题起笔 |
| 三段式强行并列 | 能两项说清就两项；按逻辑而非排比 |
| 整句只有价值判断 | bounded → 待确认删除；短文可删 |
| 翻译腔长定语 | 拆短；主谓宾靠前 |
| 每句等长抛光 | Residual Audit 时拆/并一两处即可 |

## 中英混写（有限支持）

Great question / Here's the thing / It's not X, it's Y / game changer / leverage / at the end of the day / studies show — 同族处理。只清中英混写中的常见模板语；整篇英文润色不属于本 skill。

## 反例（不要学）

- 为了「具体」编造功能列表、用户数、论文名
- 为了「像人」加「我真的不知道」「有点不安」
- 把 release note 改成散文故事
