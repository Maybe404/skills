# Long-form Workflow

Use this workflow when the user starts with a topic, notes, research, or a rough argument rather than a finished draft.

## Stages

1. **Brief**: Define audience, channel, purpose, constraints, and desired reader action.
2. **Evidence**: Separate sourced facts, user experience, interpretation, and open questions.
3. **Position**: Write one contestable central claim and its limits.
4. **Structure**: Build sections around reader questions, not a generic introduction-body-conclusion template.
5. **Opening tournament**: Draft multiple openings using genuinely different angles; select against relevance, honesty, specificity, and tension.
6. **Draft**: Write from evidence and position. Mark missing evidence instead of inventing it.
7. **Editorial review**: Test logic, counterarguments, redundancy, and scene fit.
8. **Reader simulation**: Evaluate likely confusion, distrust, boredom, and share motivation for the actual audience.
9. **Natural-writing pass**: Use the main workflow of this skill.
10. **Fact check**: Reconcile every checkable claim with the evidence record.
11. **Delivery**: Produce the publishable text and a compact unresolved-claims list.

Do not collapse all stages into one generation pass for important long-form work. Persist intermediate artifacts when working in a file-based project.
